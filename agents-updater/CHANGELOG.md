# Changelog — agents-updater

## [2.5] - 2026-08-12

### 任务末工作流复盘
- 任务结束前调用本 skill 时自动复盘本轮工作流，把过程证据分为：过期或冲突信息、工作流低效、真实踩坑、一次性或证据不足；优先删污染源或优化流程，最后才记录踩坑。
- 对工作流修复写出“原路径 → 根因 → 最小修复 → 下次理想路径”，用可见轨迹（搜索、读取、临时命令、改道、验证输出）验证；无法取证时不编造复盘结论。
- 结果正确不再等于无需治理：任务即使成功，存在重复搜索、无关阅读、临时命令或反复改道时，先修工作流，而不是把绕路沉淀成踩坑。

### AGENTS.md 证据式处理
- `agents-report` profile 改为先基于路径、消费者和冲突取证；用户已明确要求清理或改写时可据此直接实施，只有未决设计冲突会实质改变结果时才暂停询问。

### 上下文污染控制
- “上下文污染门禁/熔断”调整为“上下文污染控制”：偏离时停止扩展范围、收缩到直接相关来源继续，不再默认生成污染报告并中断；只有来源歧义或冲突直接阻塞安全完成时才报告证据并给出一个取舍问题。

### 文档与校验
- `references/maintenance-matrix.md` 新增“任务末工作流复盘”章节（证据分类矩阵 + 5 步实施核对），删除已废弃的 `issue-cards` 短指令落点。
- `references/eval-cases.md` 新增 Case 13（任务成功但工作流低效）与 Case 14（混合场景拆分低效与真实踩坑），Case 4 更新为污染控制语义。
- `agents/openai.yaml` 的 `default_prompt` 更新为：先分类任务末证据、优化低效工作流再沉淀踩坑、收敛唯一权威源并验证。
