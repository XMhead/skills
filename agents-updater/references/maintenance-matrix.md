# Agents Updater Maintenance Matrix

本文件承载 `agents-updater` 的详细判断矩阵。只有当任务需要做具体落点判断、维护 hooks/commands/tools、诊断上下文浪费或核对常见错误时才读取。

## 全局/私有分流

| 内容 | 落点 | 判断 |
|------|------|------|
| 跨项目通用流程 | 全局 skill | 不依赖服务器、玩法、插件取舍或本机项目路径 |
| 通用自动化脚本 | 全局 skill `scripts/` | 参数显式传入，不能内置某个项目默认路径、端口或业务规则 |
| 项目业务规则 | 项目指令文件 | 地图简称、端口、RCON、物品库、验证顺序、禁止读取清单 |
| 插件长期索引 | 项目 skill | 哪些文件管什么、项目硬约定、稳定踩坑 |
| 跨插件流程 | 项目 linkage/reference | 完整流程涉及 2 个以上插件，且未来会重复维护 |
| 快捷 Prompt / Command | 全局或项目 commands | 行为入口写 prompt/command；绑定项目路径、端口、玩法或工具默认值的留项目内 |
| Hook | 全局或项目 hooks/settings | 通用行为进全局；绑定特定项目启动流程、端口、目录监控的进项目 |
| Tool | 全局或项目 tools/MCP | 全局可用的外部服务进全局 MCP；项目私有 API/数据库/凭据留项目配置 |
| 单次任务记录 | 不写入 skill | 可留在 changelog、普通 docs 或配置本身 |
| 旧路径/旧事实 | 删除或替换 | 不写进"常见错误"，不保留新旧并列 |
| 冲突的设计/取舍 | 先验真或问用户 | 当前配置、源码或运行证据能确定唯一版本时收敛；设计意图、兼容策略等证据不足时，列明影响并询问用户取舍 |

迁移时先分类现有 `SKILL.md`、`references/`、`scripts/`、hooks、commands、tools；项目需要的通用语法提炼进各项目同名 skill，污染或过期内容直接删。迁移后 grep 全局同名路径、旧脚本路径、旧项目事实、旧触发名、旧 hook/command/tool 名称；能删重复就删。

## 维护 profile

| profile | 适用对象 | 门禁 |
|---------|---------|------|
| `strict-skill` | 新建或实质重写 skill | 读取 `skill-creator`；正文保持最小且可渐进披露；脚本可执行；运行 frontmatter/结构审计和必要的 forward-test |
| `compat-skillshare` | 已由 skillshare 管理的现有 skill | 保留同步入口和本地兼容约定；只改已确认噪声、过期引用或行为缺口；禁止无关批量重写 |
| `agents-report` | `AGENTS.md` 审计、降噪或冲突处理 | 先输出路径/行号/证据/消费者/冲突/取舍报告；未经明确选择不删除、合并或改写 |

## AGENTS 与权威源

| 场景 | 处理 |
|------|------|
| 多份配置内容一致 | 选一个源文件作为 canonical source；其它文件标记为同步生成物，消费者只读 canonical source |
| 多份配置内容不一致 | 列出精确路径、`LastWriteTime`、内容差异和当前消费者；若没有仓库事实或用户口径能定案，先问取舍 |
| 项目指令文件含本地凭据 | 按用户意图保留或迁移；凭据不进入全局 skill，报告只显示存在性和位置 |
| 项目明确不使用 Git | 项目 `AGENTS.md` | 复制粘贴备份是历史恢复流程；全局 Git 规则不得扩大项目操作，备份不自动成为第二权威源 |
| 取消运行目录文件的 Git 跟踪 | 只处理用户点名的索引项和对应精确 ignore 规则；保留磁盘文件，不扩大到全库清理 |

## Hooks 判断

| Hook 触发场景 | 落点 | 理由 |
|-------------|------|------|
| 自动格式化、lint 检查 | 全局 | 所有项目通用 |
| Token 用量预警 | 全局 | 通用行为约束 |
| 会话启动时加载项目特定环境变量 | 项目 | 依赖本项目路径和值 |
| 保存时触发项目特定构建脚本 | 项目 | 构建命令和参数是项目特定的 |
| 跨项目通知 | 全局 | webhook URL 必须通过环境变量注入 |

全局 hook 不硬编码项目路径；项目 hook 不写进全局 skill。复杂 hook 逻辑优先做成脚本，各 CLI settings 只做薄适配层。

## Commands 判断

| Command 类型 | 落点 | 理由 |
|-------------|------|------|
| `/continue`、`/save`、`/clear` 等通用交互 | 全局 | 所有 CLI、所有项目通用 |
| `/deploy-to-production` | 项目 | 部署目标、路径是项目特定的 |
| `/lint-check` 或 `/format` | 全局 | 可参数化接收路径 |
| `/start-server`、`/connect-db` | 项目 | 端口、密码、路径是项目特定的 |

Command 做交互入口和快捷操作；skill 做领域知识和工作流。二者职责可互相引用，但不要复制完整流程。

## Tools 判断

| Tool 类型 | 落点 | 理由 |
|----------|------|------|
| GitHub API、Slack SDK、通用 WebSearch | 全局 MCP | 可跨项目复用 |
| 项目私有数据库查询工具 | 项目 MCP | 凭据和表结构是项目特定的 |
| 文件系统操作工具 | 全局 | CLI 内置，无需额外配置 |
| 特定游戏服务器 RCON 工具 | 项目 | 地址、端口、密码是项目特定的 |

全局 MCP 凭据通过环境变量注入；项目私有 tool 放项目 `.gitignore` 保护的配置，不写入全局 skill 正文。

## Frontmatter 降噪

| 字段 | 规则 |
|------|------|
| `description` | 只写何时使用，优先 30-70 字；禁止写"触发："长串、工作流程、完整功能清单 |
| `aliases` | 只留 3-8 个高频入口词；不要把 `description` 已覆盖的普通字段名全塞进去 |
| 同名全局/项目 skill | 全局 desc 写通用触发；项目 desc 写项目覆盖触发。二者不要用同一串功能列表 |

审计时提取所有 `SKILL.md` 的 `name`、`description`、`aliases` 和路径；优先审同名 skill；搜索 `description:.*触发：`、多行 `description: |`、超过 90 字的 desc。

## 上下文浪费诊断

| 信号 | 常见根因 | 处理 |
|------|----------|------|
| 多次大范围搜索同一类文件 | 缺少文件职责速查或入口索引 | 在对应 skill 或项目指令文件补路径职责；路径只放一个权威位置 |
| 为同类检查反复写临时命令 | 缺通用脚本或脚本没有入口说明 | 通用脚本进全局；项目默认参数留项目 skill/AGENTS |
| 读取长文档后只用少量信息 | SKILL.md 太胖或 ref 没有按需拆分 | SKILL.md 保留流程，细节拆到 `references/` |
| skill 列表被长 desc 或长 aliases 挤满 | frontmatter 同时写功能清单、触发词和流程摘要 | 按 Frontmatter 降噪规则收敛 |
| 被旧路径、旧命令、旧项目事实误导 | 过期信息残留 | 删除或替换源头，并 grep 清残留 |
| 用户反复纠正同一项目口径 | 项目指令文件或插件 skill 缺硬约定 | 写到项目私有位置，不放全局 |
| 跨项目都遇到同一决策问题 | 通用判断规则缺失 | 提炼到全局 skill，项目只保留差异 |
| 同一插件 skill 在多个项目并行复制维护 | 通用语法和项目事实混在一起 | 项目同名 skill 保持自包含；全局只放参数化脚本或通用维护流程 |
| 用户反复发送短指令 | 缺少 prompt/command 入口或行为约束 | 行为入口写 commands/prompts；领域知识增强对应 skill |
| 跨 CLI 重复配置同类 hook | 没有提炼全局 hook 模板 | 通用 hook 逻辑进全局脚本或文档；CLI settings 只适配语法 |
| 同一 tool 在多个项目重复配置 | 没判断全局/项目归属 | 全局 MCP 集中配置；项目私有 tool 留项目 |
| command 功能重叠或命名混乱 | 缺少 command 命名和去重规范 | 在项目指令文件或全局 skill 约定命名前缀和作用域 |

## 上下文污染熔断

| 信号 | 动作 | 不做什么 |
|------|------|----------|
| 连续读取无关来源或重复搜索 | 暂停扩展范围，生成污染报告 | 不继续盲目扫描，不马上删文件 |
| 发现两个以上权威源或规则冲突 | 列出来源、消费者和影响，只问一个取舍问题 | 不擅自合并、猜测兼容策略 |
| 读取量增加但没有执行动作 | 回到任务目标和最小必读范围 | 不把所有可见文档都当成当前任务输入 |
| 污染不阻塞交付 | 标记 `deferred-cleanup`，先完成最小流程 | 不把治理工作混入当前执行流 |
| 污染已经阻塞交付 | 停止当前路线，等待用户选择后再继续 | 不继续消耗上下文或扩大修改范围 |

污染报告最少记录：原任务、已读来源、直接相关来源、疑似污染、冲突、影响、建议和一个待确认选项。固定 token/秒数不是唯一门槛，优先使用这些可观察信号。

## 重复短指令落点

| 用户短指令 | 落点 | 处理 |
|-----------|------|------|
| `继续` / `继续刚刚的任务` | 快捷 prompt/command | 继续当前线程未完成目标；不要重新开题，先找最新阻塞和下一步 |
| `沉淀` / `记到 skills` / `下次别踩坑` | 本 skill | 先判断全局/项目/不沉淀，再写最小长期信息并验证 |
| `加个 hook` / `配置 hook` / `hook 不生效` | 本 skill | 先判断 hook 类型和归属，再写入并验证语法 |
| `加个 command` / `斜杠命令` | 本 skill | 先判断通用/项目专属，再选择落点 |
| `加个 tool` / `MCP 工具` | 本 skill | 先判断凭据和复用范围，全局 MCP 不放项目凭据 |
| `读取并执行任务卡片：<path>` | `issue-cards` | 已废弃。Plan 标记块替代卡片，见 issue-cards skill |
| `可以` / `确认` / `对` / `看看` / `修复` | 不沉淀 | 纯确认或上下文依赖过强，不作为独立 prompt/command/skill 候选 |

## 常见错误

| 错误现象 | 根因 | 正确做法 |
|---------|------|---------|
| 把某服地图、端口、物品库规则写进全局 skill | 没先判断全局/私有边界 | 只把判断方法放全局，项目事实留在该项目指令文件或项目 skill |
| 为了"留历史"保留旧路径和新路径两套索引 | 把过期信息当成踩坑 | 删除旧事实；只有仍会重复发生且无法靠删旧信息避免的才写常见错误 |
| 每次任务结束都默认写 skill | 把自检误解为必写 | 自检只判断是否值得沉淀；一次性、临时、根因未明的信息不写 |
| 项目 skill 依赖全局同名基座才能看懂 | 把关键语法和 refs 留在全局，项目层过薄 | 把项目会用到的语法、索引和踩坑迁入项目同名 skill；全局只保留非同名工具或参数化脚本 |
| desc 写成长功能清单，还在末尾加"触发：A、B、C" | 把检索入口当正文摘要 | desc 写一句使用场景；触发词放少量 aliases 或正文触发条件 |
| 全局 hook 里硬编码某项目路径 | 没判断 hook 的全局/项目归属 | 全局 hook 用环境变量或参数；项目特定路径放项目 settings |
| 所有项目的 MCP tool 都堆在全局配置 | 没区分 tool 的复用范围 | 全局 MCP 只放跨项目复用的；项目私有 tool 放项目配置 |
| command 和 skill 触发条件重叠或互相抢 | 没协调 command 与 skill 的职责边界 | command 做交互入口；skill 做领域知识和工作流 |

## 文件职责速查

| 概念 | 典型路径 | 用途 |
|------|---------|------|
| 项目指令文件 | `AGENTS.md` / `CLAUDE.md` / `.cursorrules` | 项目私有行为规则、禁止项、业务口径、验证入口 |
| Skills | `{cli}/skills/*/SKILL.md` | 领域知识、工作流、索引；CLI 识别并可按名调用 |
| References | `{skill}/references/*.md` | skill 拆分出的详细参考文档，按需读取 |
| Scripts | `{skill}/scripts/*` | 可重复执行的自动化脚本；全局脚本不得内置项目私有默认值 |
| Hooks | `{cli}/hooks/` 或 settings 内配置 | 事件钩子；触发自动化行为 |
| Commands | `{cli}/commands/` 或 settings 内配置 | 自定义斜杠命令/快捷指令 |
| Tools | `{cli}/tools/` 或 MCP 配置文件 | 工具定义、MCP 服务器/工具、外部工具集成、工具权限 |
| Agents | `{skill}/agents/*.yaml` | 面向特定 CLI 的 agent 适配配置 |
